Loose MP3s, one book in Apple Books.

Audiobook Binder is a Mac app that gathers chapter files from a folder — even a nested library — and writes a proper .m4b with title, author, cover, and chapter marks.

Download for macOS 14+ GitHub release

Free. Runs on your Mac. Version 1.4.6 · about 3 MB

It binds the library you already have.

Point it at one book folder, or a parent folder of many books. Nested wrappers (Calibre-style 43/Title trees) become a folder list on the left. Already-made .m4b files show as already bound so you do not encode them twice.

Metadata is filled from MP3 tags, then OPF/EPUB, then the ebook filename, then the folder name. You can rewrite title, author, narrator, cover, and every chapter before you build. Uncheck a credits track. Play a chapter to be sure. Save the file next to the book, or into ~/Music/Audiobooks.

The finished file is marked as an audiobook for Apple Books (stik=2) with a chapter track. Drop it on Books, or use Open in Books at the bottom of the window.

How to bind a book

  1. 1

    Open a folder

    Choose a single book of numbered MP3s, or a library folder. Nested wrappers are scanned automatically. Nothing is scanned until you open a folder. The status bar names the folder being read.

  2. 2

    Pick a level, if you need to

    When books sit under extra folders, use the folder tree on the left. Filter by title, author, or narrator. Already-bound files stay unchecked.

  3. 3

    Edit, skip, listen

    Fix title and author. Change the cover. Uncheck chapters you do not want. Play any chapter from the list. Bitrate and save location sit under Open Folder. After a build, compare original audio with the .m4b chapter by chapter.

  4. 4

    Build

    Save in the book folder, or to Music/Audiobooks. Then Show in Finder, Open in Books, or Verify at the bottom of the window. If chapter counts and durations match, you can move the original audio files to Trash.

Install from the disk image

Download the DMG, open it, and drag Audiobook Binder into Applications.

This build is signed with a Developer ID certificate and notarized by Apple. Drag it into Applications, then open it from there.

What it expects

One book: a folder of numbered MP3s, optional cover.jpg, optional ebook/.

A library: a parent whose subfolders are books. Helper folders such as 不分章节 are skipped when numbered chapters exist.

Requires macOS 14 or later. Self-contained: no ffmpeg, Homebrew, or other extra installs. Encoding uses macOS AVFoundation.
